Uygulamalı Atölye Programı

4 Haftalık Yoğun Müfredat

Teoriyi minimumda tutup her hafta somut bir web bileşeni ve nihayetinde tam teşekküllü bir portfolyo projesi çıkarıyoruz.

01 1. Hafta

AI Prompt Mühendisliği & Modern Web Mimarisi

LLM'lerle doğru iletişim kurma; HTML5, modern DOM yapısı ve yapay zekaya doğru kodlama talimatları verme sanatı.

  • ChatGPT, Claude ve Gemini ile sistem tasarımı
  • Context yönetimi & kod yinelemeli (iterative) geliştirme
  • Temel web anatomisi ve semantik etiketleme
02 2. Hafta

Frontend UI/UX Tasarımı & Tailwind CSS

AI araçlarıyla modern, minimalist, mobil uyumlu ve göz alıcı kullanıcı deneyimleri oluşturma.

  • Tailwind CSS ile hızlı prototipleme ve bileşenler
  • Responsive (Mobil, Tablet, Masaüstü) tasarım kuralları
  • Lucide ikonları, mikro-etkileşimler ve erişilebilirlik
03 3. Hafta

Dinamik JavaScript & Yapay Zeka API Entegrasyonu

Sayfayı canlı bir uygulamaya dönüştürme; modern JS özellikleri ve tarayıcı tabanlı AI modelleri.

  • DOM manipülasyonu, Event Listener'lar ve State mantığı
  • Fetch API ile canlı API veri çekimi
  • Hata yakalama (Error Handling) ve AI ile kod debug etme
04 4. Hafta

GitHub, Git Versiyonlama ve .github.io Yayını

Projenizi üretim ortamına taşıyın, GitHub Pages ve özel alan adı bağlantılarını tamamlayın.

  • Git temelleri (commit, branch, push işlemleri)
  • GitHub Pages ile ücretsiz SSL ve hızlı hosting
  • SEO meta etiketleri ve canlı sunum günü
Kolay Yayına Alma

Projenizi 3 Adımda .github.io ile Canlıya Alın

Bu atölyede oluşturduğunuz bu dosyayı ve projelerinizi hiçbir sunucu ücreti ödemeden dakikalar içinde tüm dünyaya açabilirsiniz.

GitHub Pages Belgeleri
1

Repo Oluşturun

GitHub hesabınızda yeni bir repository açın. İsim olarak kullaniciadi.github.io ya da dilediğiniz bir repo adı verin (Public olmalı).

2

index.html Yükleyin

Bu kodu index.html olarak ana dizine (root) yükleyin ve commitleyin.

3

Pages'i Etkinleştirin

Repo > Settings > Pages sekmesine gidin. Kaynak olarak main branch / root seçin ve kaydedin. 1 dakikada yayında!
